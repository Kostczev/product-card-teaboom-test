# TeaBoom — карточка товара

Тестовое задание: вёрстка верхней части карточки товара для интернет-магазина чая TeaBoom.

## Реализовано

- Отображение информации о товаре из JSON.
- Галерея товара.
- Выбор фасовки с обновлением цены и артикула.
- Управление количеством товара.
- Отображение описания, состава, вкуса, преимуществ и характеристик.
- Адаптивная вёрстка.

## Технологии

- HTML5
- CSS3
- JavaScript
- JSON

## Запуск

1. Склонируйте репозиторий или скачайте исходный код.
2. Откройте папку проекта в VS Code.
3. Запустите `index.html` через расширение Live Server.

Локальный сервер необходим для загрузки данных товара из JSON.
